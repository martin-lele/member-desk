# 会员台 · Member Desk

面向中小酒店的本机会员储值管理工具。Python 标准库 + SQLite + 原生 JavaScript，不依赖 Node.js 构建或云数据库。

本仓库是从门店自用系统整理的**早期公开版本**。不含任何真实会员、员工账号、数据库、令牌、酒店映射或在线试用入口。下载者需独立部署，不连接作者的门店系统。

## 功能

- 会员手机号、生日、身份证资料；身份证默认脱敏显示。
- 充值、消费及流水，按整数分记账；充值门店、业绩归属员工、操作员分别记录。
- 员工注册、管理员审批、门店分配、停用与退款审批。
- 管理员与员工分角色界面。
- 百居易（Hostex）只读 API 客户端及付款同步适配代码。

## 快速开始

目前支持 macOS / Linux，建议 Python 3.10 及以上。使用 `fcntl`，Windows 暂未适配。

```sh
python3 start.py
```

浏览器自动打开本机初始化页。创建自己的管理员账号、独立密码和首家门店。没有默认账号或默认密码。首次设置密钥保存在 `data/setup-token.txt`，不要分享。

启动脚本在前台运行；保持终端开启，使用 Ctrl+C 退出。端口为 8765，需确保没有其他服务占用。程序和数据均在自己的电脑上。

也可以手动运行 `python3 app.py --port 8765`。首次设置时，在本机地址后追加 `#` 和本机 `data/setup-token.txt` 中的密钥；勿将该地址发送给他人。

## 员工登录

首次员工注册填写真实姓名与本人账号，设置至少 10 个字符的独立密码。管理员核实身份并审批、分配门店后才能使用。百居易同名账号仅用于人工核对，**没有单点登录，不验证百居易密码，也不会自动同步团队权限**。

本机 `127.0.0.1` 地址不能发给外地员工。远程部署需配置自己的 HTTPS 反向代理，再用 `--public-url https://你的域名` 启动对外入口。监听仅绑定回环地址，代理与应用应在同一主机。请勿公开转发作者的员工入口。

## PMS 适配状态

会员管理可独立使用。公开版本的自动 PMS 扣款**默认未配置、不会自动启用**。源码包含百居易适配器，但不是所有 PMS 的通用即插即用插件。

百居易文档：https://api-doc.myhostex.com/reference/overview

部署者需要开发人员完成本账号的付款方式、房费项目、门店分组映射及首次同步起点配置，并用模拟数据核验。保存 API 令牌不代表已经完成接入。

- `HOSTEX_BALANCE_METHOD_ID`：本账号“储值消费”付款方式编号。
- `HOSTEX_ROOM_ITEM_ID`：本账号房费项目编号。
- `member_payment_policy`：数据库 metadata 中与当前付款编号对应的策略。
- `member_payment_group_stores`：数据库 metadata 中的分组编号→本机门店 ID 映射。
- `member_autopay_config`：初次同步时间、授权指纹等启动状态。

这些环境变量不自动创建上述数据库映射，也不能单独启用同步。当前未提供通用配置向导。请在隔离环境完成适配，勿直接修改营业数据库试错。变更付款编号时必须重新核对历史映射。

仅明确的“已收款 + 储值付款方式 + 房费项目 + 同一会员手机号”才可扣款；订单来源、客户姓名和房价不是扣款依据。取消与改付款金额按差额处理；余额不足、缺手机号或门店不明会阻止扣款。混合支付只扣储值部分。充值仍由会员台人工核对到账后办理。

仅本机模式启动同步工作线程；`--public-url` 模式不运行工作线程。部署远程入口时，如要启用 PMS 同步，还需在同一数据目录运行一个本机模式实例，使用不同端口。

## 数据与备份

默认保存在 `data/members.sqlite3`，可用 `MEMBER_DATA_DIR` 指定独立目录。执行 `python3 backup.py` 进行备份；备份也包含敏感资料，请自行保管。API 令牌以主机受限文件保存，不上传仓库。

数据库不是加密数据库。正式使用应配置主机访问控制、磁盘加密、HTTPS、备份和恢复流程。本项目未完成独立安全审计，不应视为经过认证的财务系统。

## 已知限制

短信发送与短信找回密码尚未开通；当前界面中的短信提示不代表可发送。没有百居易团队认证接口，权限需人工审批。公共版本不附带隧道二进制、生产数据迁移脚本或商户专用配置。
